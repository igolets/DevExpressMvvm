# AGENTS.md

## What this repo is

- Educational, read-only reference for DevExpress WinForms MVVM (v21.1). The only project is `IfnsExporter/` — a .NET Framework 4.8 WinForms app (legacy non-SDK csproj, `LangVersion 9.0`).
- **It intentionally does not compile.** README states this. Do not try to "fix" the build, remove references, or convert the project format.

## Build reality (why builds fail)

- No `.sln` file. `IfnsExporter.csproj` references sibling projects **two levels above this repo**: `..\..\BOReports`, `..\..\BOSettings`, `..\..\TMCommon`, and NuGet packages at `..\..\packages\`. It expects to sit inside a larger private solution tree that is not published.
- DevExpress 21.1 assemblies are installed-product/GAC references; `TmAvt.*` DLLs come from a private NuGet feed. Neither is publicly available.
- Only MSBuild/Visual Studio can build this project type; `dotnet build`/`dotnet run` will not work. Verification is code review only.

## Architecture

- Entry: `IfnsExporter/Program.cs` → `MainView`. The app forces `ru-RU` culture; user-visible strings and even Settings property names are in Russian — keep new strings Russian to match.
- DevExpress MVVM fluent API: bindings live in each View's code-behind `InitializeBindings()` (`BindCommand`/`SetBinding` on `mvvmContext1`), not in XAML-like markup. ViewModels (`ViewModels/`) are plain POCO classes.
- Custom MVVM services (`Services/IShellService.cs`, `IBindingSourceService.cs` with `Impl/`) are registered via `mvvmContext1.RegisterService(...)`; dialogs via `DialogService.CreateXtraDialogService`.
- Data flow: `MainViewModel` loads from SQL Server (connection string in user `Settings`) or Excel (`Csv/` via FileHelpers + NPOI), then exports XML per `Protocol/Reestr-5-02.xsd` or Excel using the template `Шаблон.xlsx` (Content item, copied to output — required at runtime).

## Gotchas

- **Non-SDK csproj: new `.cs` files must be added to `<Compile Include>` in `IfnsExporter.csproj` manually** or they are silently not compiled. Same for resx/content items.
- `Protocol/Reestr-5-02.cs` is generated by `xsd.exe` from `Reestr-5-02.xsd` — never hand-edit it. Regenerate with `Protocol/XsdConvert.bat` (hard-coded path to Windows SDK 8.1A tools).
- WinForms Designer files (`*.Designer.cs`, `.resx`) are paired via `DependentUpon`; don't break those groupings when moving files.
- Git history is tiny (3 commits, `main` branch); there is no CI, no tests, no lint config. Don't invent verification commands.
